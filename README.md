# 🚔 Crime Management System

**Rajkot Crime Branch – Police Management System**

## 📌 Project Overview

The Crime Management System is a Java-based application designed to manage and organize crime-related information efficiently. It helps police departments maintain FIR records, criminal details, police officer information, and investigation records. The system aims to reduce manual paperwork, improve data organization, and provide easy access to important crime-related information.

## ✨ Features

- **FIR Management:** Maintain and manage First Information Report (FIR) records.
- **Criminal Management:** Store criminal details, crime history, and custody status.
- **Police Records:** Maintain police-related information.
- **Crime Records:** Manage crime categories, incident locations, and applicable sections.
- **Case Tracking:** Track investigation and case status.
- **Data Management:** Maintain structured records using JSON files.
- **Java Application:** Simple application execution using Windows scripts.

## 🚀 How to Run

**Method 1: Using Batch File**

1. Download or clone this repository.
2. Make sure Java JDK is installed.
3. Open the project folder.
4. Double-click `run.bat`.
5. The application will compile and launch automatically.

**Method 2: Using PowerShell**

1. Open PowerShell inside the project directory.
2. Execute the following command:

```powershell
.\run.ps1
```

The script will compile the Java files and launch the application.
